# WealthAI

WealthAI is a French-language mobile wealth assistant built with Expo, React Native and an Express API.

## Included

- Mobile app in artifacts/mobile
- API server in artifacts/api-server
- Shared workspace libraries in lib
- RevenueCat subscription setup with server-side configuration scripts
- Existing portfolio, budget, accounts, withdrawals, QR and AI features preserved

## Safety

No API keys, bank credentials, session secrets or private certificates belong in this public repository. Configure secrets through the deployment environment. AI recommendations never initiate transfers without explicit user approval.
